# Finance, Holidays & OG Image Tools API

A set of fast, lightweight utility endpoints developers reach for again and again: financial calculators, public-holiday lookups, and dynamic Open Graph social-image generation. One key, several tools, no heavy setup.

**Live on RapidAPI:** https://rapidapi.com/cesaricf79/api/finance-holidays-and-og-image-tools

Free tier included. Get your key and ready-to-paste snippets (curl, Python, Node) on the listing above.

## What's inside

- Finance calculators — loan/mortgage payments, compound interest, and other everyday money math, as clean JSON.
- Public holidays — look up official holidays by country and year. Useful for scheduling, business-day math, and calendars.
- Dynamic OG images — generate an Open Graph / social share image on the fly from text and parameters, so your links look right when shared.

## Typical uses

- Adding a loan or savings calculator to an app without writing the math.
- Skipping weekends and holidays in scheduling and SLA logic.
- Auto-generating share images for blog posts, listings, and dashboards.

## Notes

- Simple REST calls that return JSON, or an image for OG generation.
- Deterministic and quick; nothing to install.
- Designed to be cheap to run at scale.

Full request/response examples and per-language code are on the RapidAPI listing.
